# SmartFace-Attendence-system
AI-powered face recognition attendance system with real-time detection, LBPH training, and automated CSV reporting.
📌 SmartFace Attendance System
SmartFace Attendance System is a real-time face recognition-based attendance management application built using Python and OpenCV. The system captures student facial data, trains an LBPH face recognition model, and automatically marks attendance through a user-friendly Tkinter GUI.
The application ensures structured data handling, secure model training with password protection, and automated CSV-based attendance reporting.

🚀 Key Features
-> Real-time face detection using Haar Cascade
-> LBPH-based face recognition model training
-> Automated attendance marking with duplicate prevention
-> Password-protected training system
-> GUI-based student registration and profile management
-> CSV attendance report generation with timestamp
-> Auto-directory creation and error handling
-> Clean dashboard-style Tkinter interface

🛠 Technologies Used
1.Python
2.OpenCV (LBPH Face Recognizer)
3.Tkinter (GUI)
4.NumPy
5.Pandas
6.CSV File Handling
7.Haar Cascade Classifier

📂 How It Works
1.Register a student by capturing facial images.
2.Train the LBPH model (admin password protected).
3.Start attendance tracking.
4.Recognized faces are logged into a dated CSV file.
5.Attendance records can be viewed instantly.
